📄 README.md

pulseloader-analysis

Analysis files from my writeup on PulseLoader — a loader delivering second-stage payloads via phishing lures, active against European targets in late 2024.

Contents

  • indicators.txt — C2 domain, IP, URL pattern, and sample hash
  • pulseloader.yar — YARA rule for network and host-based detection
  • beacon_decode.py — decodes the base64-encoded beacon payload

Key indicators

C2 domain : cdn-telemetry-eu.net
C2 IP     : 91.214.47.138
Beacon    : HTTP POST /api/v1/metrics/push (every 4 min)
User-agent: spoofed Windows Update
SHA256    : 4a7f3c9e1b2d8f0a6e5c4b3d9f1a2e7c4b8d3f0a9e6c5b2d1f8a4e7c3b0d9f2

The C2 domain has been submitted to blocklists and is no longer active. Full writeup on my site.
